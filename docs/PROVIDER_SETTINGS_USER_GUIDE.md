# Content OS 设置与生产指南

正常入口：Workbench → 设置。所有操作在页面完成。

## AI 与 API

内置卡片和自定义卡片来自同一个注册表。自定义可建立多条服务记录，每条有稳定 ID，改名不会更换密钥。API 地址允许 https 和本机 http 地址，Model ID 可自由填写；不支持模型列表接口时仍可手填。设置默认无自动请求。测试失败显示地址、鉴权、余额、频率、模型、协议或超时原因，可展开脱敏技术详情。

手工声明能力只表示声明，实际测试通过才表示已验证。没有专用 Adapter 的 Anthropic/Gemini/私有协议当前不可用。Custom Headers 尚未开放。

## 角色与模型

逐一选择服务并保存。纯文本模型不能用于视频审查。自定义服务使用中的角色或备用配置必须先更换，才能删除该服务。导出仅包含非敏感配置；其他电脑导入后需要重新配置密钥。

## 声音与 TTS

声音注册表与文本服务分别管理。可启用已授权本地克隆音色、MiniMax TTS 或豆包 TTS。试听生成短音频，正式配音必须等待 H2 和分镜批准，并使用批准的完整脚本。当前本地 CosyVoice3 已实际试听；MiniMax 已实际试听；豆包声音服务当前鉴权失败。音色不存在时检查准确的 Voice ID。配置完成并不保证账号有声音接口权限。

## 数据与隐私、预算与费用

仅本地阻止远程请求。每次询问的确认绑定当前项目、目的、接收服务和本次内容，不可复用。允许项目云调用仍受预算和能力检查限制。未知费用策略支持允许、询问、阻止；单次、当天与项目预算按 USD 计算，无法估价且设了上限会阻止请求。估算费用不是供应商实际账单。备用策略不会把真实流程自动切成 Mock。

## 审查与用户确认

来源 → 原文证据 → 事实 → 声明 → 脚本的绑定必须完整。独立审计不看生产模型的完整解释。脚本修订会重新审计；模型分歧与 QA 否决创建返工，不直接改上游。用户分别确认 H2、分镜和 H3，终稿批准不授予发布权限。只有 08 能写正式错误与规则。

当前真实任务已完成脚本审计 PASS，H2 已由用户本轮“继续”确认，预配音分镜已获用户批准，正式本地声音实测84.76秒；配音后第3版分镜已完成，等待新版时序与字幕确认。完整脚本见 examples/activation/H2_SCRIPT_REVIEW.md。正式时长需实际配音测量，不能以字数推算为验收证据。
