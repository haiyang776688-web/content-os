# CS-001 · Implementation record

- **Action allocator:** `allocate_action(intent, recent_action_ids, beat_id, project_id, actions)` selects only registered actions whose semantic intents match. A two-beat recent window is preferred; the `project_id + beat_id` digest makes selection reproducible. A sole candidate or exhausted window falls back deterministically. An explicit Director or human action remains intact.
- **Template allocator:** the previous single semantic-to-template choice is now an allow-list over existing registered templates. It filters by media and character prerequisites, avoids recently used eligible variants and preserves deterministic rebuilds. The generic `CHARACTER_LOGO` layout is excluded from EXPLAIN because an arbitrary screenshot is not a logo.
- **Motion primitive:** Remotion applies a restrained beat-long slow zoom/pan to media, and conditional subtle character scale only for selected reaction/summary/close-up contexts. Text and subtitles keep their original timing and positions. This is not a motion engine or proof of better pacing.
- **Director guidance:** existing instructions now state the user's anti-PPT criteria, evidence priority, nonmechanical XIAO-Y use and information change. Registered screenshot IDs include safe display labels so the Director can distinguish research, script and audit images. No DirectorIR field was added. The generated-output schema has one authoritative injection point rather than being repeated in several prompts.
- **Contact sheet:** a generated local `contact-sheet.html` and a Workbench-wide still overview place every beat's start/end frames side by side. This supports spotting repeated pose, layout and white space before final voice/render.
- **Controlled 1:N operation:** the storyboard workbench can split an existing beat into two Director-owned beats bound to the same script segment. It halves the timing estimate without changing scene duration, records a revisioned command and lets the operator assign a different media image to either beat. This is the smallest GUI route to test AudioClock's segment-internal retiming.
- **QA:** `ACTION_REPETITION` and `TEMPLATE_REPETITION` detect consecutive or short-window overuse in the actual EDT. Both remain warnings; creative taste is not a hard-coded blocker.
- **Media fix found in GUI test:** the Director contract used `MediaAsset.kind` although the registered model field is `type`. It now accepts online IMAGE/VIDEO/SCREENSHOT assets, with a regression test.

The new test module covers deterministic allocation, semantic eligibility, one-segment/two-beat retiming without changing VOICE, revisioned GUI splitting, visual timing, Director schema stability, imported media registration and QA warnings. The full suite passed **213 tests** after the controlled split implementation. Final creative findings are in `03_RESULTS.md`; code passing alone does not complete the spike.
