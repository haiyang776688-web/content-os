## 已观察到的失败

CS-001 的 15 个 visual beats 中只有四个带导入截图，其他 11 个没有真实截图。样片虽然使用五种 XIAO-Y action ID、八种已注册模板，并有一次人工建立的 1:N segment/beat 关系，整体仍表现为白底中摆放人物、短文本或小截图，再切换下一页。部分画面维持约六至九秒而没有增加足够的新视觉信息。

研究截图在原 CS-001 构图中不足半幅宽度，正常观看尺度下控件不能承担有效的证明工作。动作 ID 不同却仍有接近的摊手轮廓，模板 ID 多也没有带来同等程度的主角、信息结构与镜头尺度变化。七段小幅持续 zoom 的存在，没有改变这些问题。

VPS B 把证据放大、把关键控件标出来，修复 `Fact ID` 字幕碎裂，降低了读图负担。但是其中段仍在同一张空导入截图上替换“模型候选引文”“人工确认后才是 Fact”等标题。它没有显示对应的软件状态变化，画面句法仍近似“一个证据页面 + 一条标题 + 字幕”。motion-off 保留大部分可读性收益，进一步说明慢慢放大不是解决 PPT 感的充分条件。

这些观察来自 `00_SCOPE.md` 记录的全片密集抽帧、完整 timeline 及原尺寸重点帧检查；不声称完成实时连续声画播放。

## 历史报告的过期结论与误归因风险

- Council Synthesis / Claude Review 对 first-match 动作分配、完全没有持续运动、缺少明确 anti-PPT 提示的发现有具体旧基线；CS-001 已加入确定性动作/兼容模板分配、部分重复告警、微幅连续运动、审美提示、截图标签和全局 contact sheet。不能把这些旧缺陷原封不动当作 VGB 当前代码事实。
- 旧 Claude Review 把持续慢 zoom 列为最高创作回报、把“nothing moves once revealed”称作主要可确认原因。CS/VPS 的后续对照证明，该单因解释不足：图片微动存在，PPT 感仍在。这里修正的是因果信心，不是否认以前代码确实静止。
- CS 的确定性分配、八模板与人工 1:N 已经跑通；这只关闭部分工程问题，没有关闭创作问题。不能用这次工程进展继续宣称只需加几个模板或动作。
- 真实 CS AudioTimingMap 有 measured segment boundaries，但 word ranges / raw word timestamps 为空。不能把 schema 能存 word timestamps 写成这个声音已有逐字对齐。
- VPS 的 `VISUAL_STATE_HOLD` 是人手标注 state 边界的诊断，不是衡量真实认知变化的客观评分。`3.24 秒`不能升级为全局质量 Gate。
- VPS 的“Human visual-model PASS”不是用户验收。用户的本次否定优先，代理推荐与用户选择须分开记录。
- CS 的 **213 passed**、VPS 的 **216 passed**是各自记录的工程验证结果；这里没有把它们表述成本轮重新执行的测试，更不能当作审美成绩。

## 本次需要隔离的假设

A 检验真实 UI 作为持续视觉空间是否比“截图放在卡片中”更可信、更愿意看；B 检验人物只在有明确任务时参与，能否保持品牌同时减少主持人贴纸感；C 检验同一引用关系跨镜头递进，能否比完整页面/标题切换更有解释力。

三者可能全部失败。当前证据素材缺乏真实操作状态变化，可能限制产品纪实方向；白底、现有 IP 动作范围或题材本身也可能限制效果。这些是需要看片判断的假设，不是已证实的根因，更不是现在更换架构的授权。

本文件不提出组件 KEEP / MODIFY / REPLACE / DELETE 清单。用户选择视觉方向之前，不把专用镜头、短片 timing、解释图示或自评结果接入正式生产。
