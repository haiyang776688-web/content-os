# VLA-001 · Scope

VLA-001 tests the next narrow step after VRE-001: an opt-in compatibility adapter projects ordinary `DirectorIR` beats, locked script segments, fact bindings and registered evidence into DEC-011 `XIAO-Y Evidence Editorial` `ShotPlan` records. It also adds a pre-render Storyboard Review contract with representative frames, editable semantic fields, rejection and revision-bound approval.

This is an isolated experimental path. It does not replace the formal `DirectorIR`, `VisualResolver`, Storyboard Gate or production default. It does not start a four-minute film, platform profiles, audio-first work, analytics, publishing or HyperFrames.

The two required tests are:

- **Test A — Known F2 Regression:** frozen VGB-002 F2 script, facts, registered evidence, captions and voice.
- **Test B — Unseen Content Generalization:** a new 44.6-second script about pre-render storyboard responsibility, using tracked Content OS storyboard/workbench screenshots as evidence. No VGB/VRE ShotPlan was used and no shot was hand-authored.

The Test B MP4 is a visual-language validation artifact. It intentionally does not generate a new voice track; this prevents VLA-001 from becoming an audio-first or voice-provider task.
