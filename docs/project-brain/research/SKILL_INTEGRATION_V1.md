## Rejected sub-principles

The following are `REJECT`, even where another part of the source item is absorbed:

- vendor-specific production stacks or APIs as Content OS architecture;
- banning Remotion or migrating the accepted path to another renderer;
- fixed shot duration, fixed Hook duration, fixed WPM or universal Beat counts;
- platform algorithm rankings, fixed posting times and invented performance metrics;
- style imitation, complex film-camera systems and universal cinematic language;
- Seedance/AI-generated-video workflow as the primary Content OS path;
- a second final Gate vocabulary parallel to PASS / FAIL / PASS_WITH_RISK;
- direct installation or whole-package copying of external Skills.

## Visual-system absorption

The current visual slice consumes these principles in code rather than leaving them as prose:

- `visual_job` validates allowed Shot Types and treatments;
- protagonist declarations generate layer hierarchy and a one-primary check;
- Evidence Treatments create crop/highlight/relation operations with provenance;
- `character_role` restricts action allocation;
- Motion Semantics compile to explicit primitives;
- rhythm diagnostics measure semantic visual changes without imposing fixed seconds;
- Storyboard/QA can project the exact semantic plan that generated the pixels.

SEO, titles, covers, platform hooks, publishing and Analytics stay deferred. Audio-first timing and Narration Units remain intentionally out of this iteration.
