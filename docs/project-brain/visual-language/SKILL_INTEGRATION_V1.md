# Skill Integration v1 · Visual application profile

The canonical item-by-item classification lives in [research/SKILL_INTEGRATION_V1.md](../research/SKILL_INTEGRATION_V1.md). This file only states how accepted visual principles enter XIAO-Y Evidence Editorial, avoiding a second Skill truth source.

| Accepted principle | Contract destination | Runtime consumer |
| --- | --- | --- |
| Evidence-first | Visual Job + Evidence Treatment | ShotPlan validator and Visual Compiler |
| One Beat / one visual protagonist | Visual Language | ShotPlan validator and protagonist QA |
| Prove / Demonstrate / Compare | Visual Job | allowed-shot/treatment table |
| Narration-driven visual response | Rhythm Rules | timing anchors and rhythm diagnostics |
| Semantic Beat | Director planning boundary | Beat-to-ShotPlan adapter; audio-first implementation remains deferred |
| Human review | Storyboard Gate and H3 | review projection and gate, not model voting |
| Cinematic director thinking | shot scale, intention, progression and focus | Shot Plan and semantic/visual QA |

Explicitly excluded from this visual core are style imitation, complex cinema camera systems, fixed shot duration, SEO, platform titles, Xiaohongshu cover tactics, Douyin hook formulas, publishing and Analytics. These remain either rejected principles or deferred Platform Profile/heuristic work.
